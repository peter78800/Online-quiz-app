Project Description

QuizNova is a responsive web-based Online Quiz Application
developed using HTML, CSS, and JavaScript.

The application provides an interactive platform where
students can test their knowledge by answering multiple-choice
questions from different academic subjects.

QuizNova allows students to select quiz categories,
answer questions within a specified time, receive
automatically calculated scores, and review their answers.

The application provides a user-friendly dashboard
where students can monitor their quiz performance,
view previous attempts, and track their achievements.

QuizNova includes five quiz categories: Computer Science,
Mathematics, General Knowledge, English Language,
and Science.

The application uses the browser’s Local Storage
to save quiz history and theme preferences.

This project demonstrates the practical application
of front-end web development technologies in developing
an interactive online assessment application.

Application Features

1. Dashboard

The application provides a dashboard displaying:

* Total Quiz Attempts
* Average Quiz Score
* Best Quiz Score
* Total Quizzes Passed
* Recent Quiz Results

The dashboard statistics update automatically
when students complete quizzes.

2. Quiz Categories

QuizNova provides five quiz categories:

* Computer Science
* Mathematics
* General Knowledge
* English Language
* Science

Each category contains 10 multiple-choice questions.

The application contains a total of 50 quiz questions.

3. Quiz Instructions

Before starting a quiz, students can view
important information, including:

* Quiz category
* Total number of questions
* Quiz duration
* Minimum passing score
* Quiz rules and instructions

Students must click the Begin Quiz button
to start answering questions.

4. Interactive Quiz System

Users can:

* Select a quiz category
* Start a quiz
* View multiple-choice questions
* Select answers
* Change selected answers
* Navigate between questions
* Submit completed quizzes

Each question contains four answer options.

Only one answer can be selected per question.

5. Quiz Countdown Timer

QuizNova includes a countdown timer.

Each quiz has a duration of 10 minutes.

The timer begins when the student
starts the quiz.

The application displays a warning
when the remaining time becomes low.

When the timer reaches zero,
the quiz is submitted automatically.

6. Question Navigation

The application allows students to:

* Move to the next question
* Return to previous questions
* Navigate directly to a question number
* Identify answered questions
* Change answers before submission

A progress bar displays the student’s
current position within the quiz.

7. Automatic Quiz Scoring

QuizNova automatically calculates
quiz scores after submission.

The system displays:

* Total Questions
* Correct Answers
* Incorrect Answers
* Percentage Score
* Pass or Fail Status

The minimum passing score is 50%.

8. Quiz Results

After submitting a quiz, students
can view their performance.

The result page displays:

* Quiz score percentage
* Number of correct answers
* Number of incorrect answers
* Total questions
* Pass or fail status

The application also displays
a circular score indicator.

9. Answer Review

QuizNova allows students to review
their answers after completing a quiz.

The answer review feature displays:

* Quiz questions
* Selected answers
* Correct answers
* Incorrect answers
* Explanations of correct answers

This feature helps students understand
their mistakes and improve their knowledge.

10. Quiz History

Users can:

* View previous quiz attempts
* Check quiz categories
* View previous scores
* View percentage results
* Check pass or fail status
* View quiz dates
* Delete individual quiz results
* Clear all saved quiz history

11. Leaderboard

The application provides a leaderboard
that displays the highest quiz scores.

The leaderboard includes:

* Quiz ranking
* Quiz category
* Score
* Percentage
* Quiz date

The leaderboard displays the top 10
locally saved quiz attempts.

The leaderboard is browser-based
and does not display results
from other users or devices.

12. Dark and Light Mode

The application provides a theme toggle
that allows users to switch between
dark and light display modes.

The selected theme is saved
using browser Local Storage.

13. Responsive Design

QuizNova is designed to work on:

* Desktop computers
* Laptop computers
* Tablets
* Smartphones

14. Local Storage

The application saves completed quiz
results and theme preferences
using browser Local Storage.

Saved information remains available
after refreshing the page, provided
the browser’s website data has
not been cleared.

System Requirements

To run QuizNova, you need:

* A computer or smartphone
* A modern web browser
* JavaScript enabled
* Visual Studio Code (optional)
* Internet connection for accessing the hosted version

No backend server or database installation is required.

How to Run the Application

1. Download or clone the GitHub repository.
2. Extract the downloaded project if necessary.
3. Open the project folder.
4. Open index.html in a web browser.

Alternatively:

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select “Open with Live Server”.

The application will open in your browser.

How to Use QuizNova

Starting a Quiz

1. Open the application.
2. Click “Quiz Categories”.
3. Select a quiz category.
4. Read the quiz instructions.
5. Click “Begin Quiz”.
6. The quiz questions will appear.
7. The countdown timer will begin.

Answering Quiz Questions

1. Read the displayed question.
2. Review the four answer options.
3. Click the correct answer.
4. The selected answer will be highlighted.
5. Click “Next” to continue.

Navigating Between Questions

1. Click “Next” to move forward.
2. Click “Previous” to return to an earlier question.
3. Click a question number to navigate directly.
4. Change a selected answer if necessary.

Submitting a Quiz

1. Answer the quiz questions.
2. Click “Submit Quiz”.
3. Confirm the submission.
4. The application will calculate the score.
5. The result page will appear.

If the timer reaches zero,
the quiz will be submitted automatically.

Viewing Quiz Results

1. Complete and submit a quiz.
2. View the calculated percentage score.
3. Check the number of correct answers.
4. Check the number of incorrect answers.
5. View the pass or fail status.

Reviewing Quiz Answers

1. Complete a quiz.
2. Click “Review Answers”.
3. View the questions.
4. Check the correct answers.
5. Read the explanations.
6. Click “Back to Results” when finished.

Viewing Quiz History

1. Navigate to “Quiz History”.
2. View previous quiz attempts.
3. Check quiz scores and percentages.
4. View the dates of completed quizzes.

Deleting Quiz History

1. Navigate to “Quiz History”.
2. Locate the quiz result.
3. Click “Delete”.
4. Confirm the deletion.

To delete all saved results:

1. Open “Quiz History”.
2. Click “Clear History”.
3. Confirm the action.

Viewing the Leaderboard

1. Navigate to “Leaderboard”.
2. View the highest quiz scores.
3. Check the ranking positions.
4. Compare previous quiz performances.

Changing the Display Theme

1. Locate the theme toggle in the sidebar.
2. Click “Dark Mode” to enable the dark theme.
3. Click “Light Mode” to return to the light theme.

Data Storage

QuizNova uses browser Local Storage.

The following storage keys are used:

* quiznova_history
* quiznova_theme

Quiz History

The quiznova_history key stores
completed quiz results.

Saved information includes:

* Quiz category
* Number of correct answers
* Number of incorrect answers
* Total questions
* Percentage score
* Pass or fail status
* Quiz completion date
* Selected answers

Theme Preferences

The quiznova_theme key stores
the selected display theme.

Data is stored locally in the user’s browser.

The application does not require MySQL,
PHP, or an external database.

Project Limitations

1. The application does not support user registration.
2. Quiz results are not synchronized across devices.
3. The leaderboard is limited to locally saved results.
4. Clearing browser storage can remove saved quiz history.
5. The application does not currently use an online database.
6. Quiz questions are predefined in JavaScript.
7. Each category contains 10 questions.
8. The quiz duration is fixed at 10 minutes.
9. The passing score is fixed at 50%.
10. The application does not currently allow administrators to add questions through the interface.
11. Unfinished quizzes are not restored after refreshing the page.
12. The application does not generate downloadable result reports.
